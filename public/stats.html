By level

By day

Days are cut in this machine's timezone, off the player's own clock. Furthest is the highest level anyone finished that day.

By build

⚠ First and last seen are players' clocks, not deploy times. build.py stamps a git short hash, which carries no time, so the only stamps available are read off t — and real rows arrive hours early and hours late from people whose device clock is simply wrong. A + on the hash means the tree was dirty when it was built: those rows were played on code that is not the commit they name.

By source

Where the game was played. GA ran is the share of rows whose gtag.js actually loaded — when that sits near zero the GA property is empty because the script never arrived, not because the tracking is wrong (ANALYTICS.md §6). ⚠ Test games is blank until the checkbox counts them in: it says which host they came from, and the rows are filtered out of every table before it can say anything.

Boosters

A revive is two rows, not one: the loss is posted before the player pays, so the bought continuation is a second row carrying revive. Counting rows counts games, not levels attempted.
